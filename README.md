# Bilibili 黑名单增强助手 (Bilibili Blocklist Enhancer)

一个基于 Chrome Extension (Manifest V3) 开发的 Bilibili 浏览体验增强工具。提供关键词屏蔽、快捷拉黑、用户数据透视等功能，帮助你净化 B 站首页和评论区。

## 核心功能

*   **🚫 关键词屏蔽**：
    *   支持设置多个关键词（如“营销号, 标题党”）, 用逗号隔开, 半角全角都行(，,)。
    *   自动扫描首页、搜索页、热门页的视频标题。
    *   **智能屏蔽**：不仅匹配标题，还会异步检查视频的 Tags，如果 Tag 命中关键词也会屏蔽。
    *   屏蔽后卡片高亮并覆盖“拉黑UP”快捷按钮。
*   **⚡ 快捷拉黑/解除**：
    *   在评论区、动态列表（含直播区“正在直播”、纯文字/专栏动态）、排行榜、热门视频等出现用户名的地方，自动插入“拉黑/解除”按钮。
    *   直播区主播名通过“关注栏 DOM → 关注列表 API → 用户搜索接口”三级解析 UID，未关注的博主也能识别。
    *   无需进入个人主页即可快速管理黑名单；**拉黑后 toast 附“撤销”按钮**，误拉黑一键恢复。
*   **🔍 悬停数据预览**：
    *   **用户详情**：鼠标悬停在用户名上，显示粉丝数、视频数、平均时长及**词云**（翻页拉取全量投稿，基于标题+简介生成，参照 BiliScope 做法）。
    *   **视频详情**：鼠标悬停在视频封面上，显示视频 Tags 和 AI 总结（如果有）。
    *   **快捷复制**：悬停窗支持一键复制 UID。
*   **📋 黑名单管理**：
    *   点击插件图标打开管理面板：**翻页拉取完整黑名单**，支持按用户名/UID 搜索过滤、一键解除拉黑、**JSON 导出备份与导入批量恢复**。

## 安装说明

由于本项目尚未发布到 Chrome 应用商店，请通过“开发者模式”安装：

1.  下载本项目代码到本地（点击 Code -> Download ZIP 并解压）。
2.  打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/`。
3.  打开右上角的 **“开发者模式” (Developer mode)** 开关。
4.  点击左上角的 **“加载已解压的扩展程序” (Load unpacked)**。
5.  选择本项目所在的文件夹（即包含 `manifest.json` 的文件夹）。

## 使用指南

1.  **设置关键词**：点击浏览器右上角的插件图标，在输入框中输入关键词（用逗号分隔），点击保存。刷新 B 站页面即可生效。
2.  **拉黑用户**：在评论区或视频列表，点击用户名旁边的“拉黑”按钮。拉黑成功后可点 toast 上的“撤销”按钮恢复。
3.  **查看详情**：鼠标悬停在用户名或视频封面上等待 0.5 秒。
4.  **管理黑名单**：点击插件图标 → “读取黑名单”查看完整列表，可按用户名/UID 搜索，点“解除”移除；用“导出 JSON”备份、“导入 JSON”批量恢复或批量拉黑。
